# Data contents

- `raw/`: documentation only; raw PubMed data are not distributed.
- `manifests/`: PMID-only manifests identifying the exact historical PubMed retrieval (55,446 PMIDs) and final modeling corpus (54,050 PMIDs).
- `validation/`: final curated expert annotation workbook.
- `derived/`: aggregate curation, primary temporal, sensitivity, sentinel-topic, and decomposition outputs that do not contain the raw abstract corpus.

The PMID manifests contain identifiers only and do not redistribute titles, abstracts, or raw PubMed XML.
